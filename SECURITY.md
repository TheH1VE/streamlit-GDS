# Security policy

## Supported versions

This project is currently pre-1.0. Security fixes are applied to the latest
version on the `main` branch only.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use the repository's
private GitHub security-advisory reporting flow and include:

- the affected component and version;
- a minimal reproduction;
- the potential impact; and
- any suggested mitigation.

Do not include real credentials, personal data, or production service data.
Maintainers should acknowledge a report within 5 working days and coordinate a
fix and disclosure timeline according to its severity.
